## 1. System Architecture

**Type:** USB-portable offline desktop application — no cloud backend, no remote data processing.

**Three-tier local architecture:**

| Tier | Technology | Version | Role |
|------|-----------|---------|------|
| Desktop shell | Electron | 40.x | Process lifecycle, IPC, OS integration, tray, auto-backup |
| Frontend | Next.js (React 19, TypeScript) — static export | 16.x | Application UI in Electron renderer |
| Backend | ASP.NET Core (.NET 10, C#) — sidecar | 10.0.103 | REST API, business logic, persistence |

**Communication:** Electron spawns the .NET backend as a sidecar process bound to `http://127.0.0.1:[dynamic-port]`. The renderer communicates via HTTP with the `app://lumio` custom protocol. All API calls are gated by `LocalOriginValidationMiddleware` (ADR-004).

**Deployment model:** Self-contained Windows x64 ZIP artifact; USB-portable. No installer required. The database and user data live in the `data/` directory relative to the executable.

## 3. Security Architecture

| Control | Implementation | Status |
|---------|---------------|--------|
| Encryption at rest | SQLCipher AES-256 per profile database | ✅ Implemented |
| Key derivation | PBKDF2-SHA512, ≥310 000 iterations | ✅ Implemented |
| Brute-force protection | 5-attempt lockout, 15-minute timeout | ✅ Implemented |
| Heir access | Shamir Secret Sharing (threshold scheme) | ✅ Implemented |
| API boundary | Loopback-only + `LocalOriginValidationMiddleware` | ✅ Implemented (ADR-004) |
| BSN masking in logs | Serilog `BsnMaskingEnricher` | ✅ Implemented |
| CSRF / XSS | DOMPurify + Electron `contextIsolation: true` | ✅ Implemented |
| Secret scan | TruffleHog (currently in disabled CI) | ⚠️ CI DISABLED — DEC-110: lokale gate (`dotnet test` + `npm run build` + `npx tsc --noEmit`) als tijdelijk alternatief |

## 4. Data Architecture

| Aspect | Detail |
|--------|--------|
| Storage technology | SQLite (per-profile encrypted file) |
| Data directory | Relative to executable: `../data/` (portable); configurable via `LUMIO_DATA_DIR` |
| Migration strategy | EF Core Migrations; auto-apply on dev unlock; manual SQL script for production updates |
| Backup | Automatic encrypted backup (Electron auto-backup scheduler) |
| Video storage | `data/videos/` — filesystem; **AES-256-GCM versleuteling gepland SP-3-001** (huidig: onversleuteld — GAP-DATA-002) |
| Audit log | 90-day retention via background rotation service |
| Data isolation | One encrypted SQLite file per user profile; no cross-profile access |

**Domain aggregates:** Eigenaren · Erfgenamen · Testamenten · WilsVerklaringen (euthanasie, donor) · FysiekeBezittingen · Bankrekeningen · Schulden · DigitaleAccounts · CryptoWallets · Documenten · Videoboodschappen · Noodcontacten · Uitvaartinstructies · AuditLog · Statistieken
