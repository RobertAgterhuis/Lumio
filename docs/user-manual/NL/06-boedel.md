# 6. Boedel

Op de pagina **Boedel** registreert u uw fysieke bezittingen, bankrekeningen, verzekeringen en schulden. Lumio berekent automatisch een financieel overzicht van uw bruto en netto nalatenschap.

> **Navigatie:** Klik in de zijbalk op **Boedel** of gebruik sneltoets `G` → `E`.

---

## 6.1 Overzicht

De pagina bevat:

- **Financieel overzicht** — samenvattende cijfers bovenaan
- **Vier tabbladen** — Bezittingen, Rekeningen, Verzekeringen en Schulden

> **Juridische opmerking:** Het onderscheid tussen privévermogen en gemeenschappelijk vermogen is van belang voor de verdeling van uw nalatenschap (BW Boek 4).

---

## 6.2 Financieel overzicht

Bovenaan de pagina toont een overzichtskaart zes kerngetallen:

| Kengetal | Beschrijving | Kleur |
|----------|-------------|-------|
| **Bezittingen** | Totale geschatte waarde van al uw bezittingen | Groen |
| **Saldi** | Totaal saldo van al uw bankrekeningen | Groen |
| **Verzekeringen** | Totaal verzekerd bedrag | Groen |
| **Schulden** | Totaal openstaande schulden | Rood |
| **Bruto nalatenschap** | Bezittingen + Saldi + Verzekeringen | Groen |
| **Netto nalatenschap** | Bruto nalatenschap minus Schulden | Groen of Rood |

> **Tip:** Houd uw gegevens actueel — de bedragen worden automatisch berekend op basis van de items die u invoert.

---

## 6.3 Bezittingen

### Bezit toevoegen

1. Ga naar het tabblad **Bezittingen**
2. Klik op **Toevoegen**
3. Vul de gegevens in:

| Veld | Toelichting |
|------|-------------|
| **Categorie** | Type bezitting (zie hieronder) |
| **Omschrijving** | Beschrijving van het item |
| **Geschatte waarde** | Waarde in euro's (€) |
| **Locatie** | Waar het item zich bevindt |
| **Bestemde erfgenaam** | Aan wie u dit item wilt nalaten (optioneel) |
| **Vermogenssoort** | Privé of Gemeenschap |
| **Notities** | Aanvullende informatie |

4. Klik op **Opslaan**

### Categorieën

| Categorie | Aanvullende velden |
|-----------|--------------------|
| **Onroerend goed** | Kadastraal nummer |
| **Voertuig** | Kenteken |
| **Sieraden** | — |
| **Kunst** | — |
| **Elektronica** | — |
| **Meubels** | — |
| **Overig** | KvK-nummer (voor bedrijfsbelangen) |

### Vermogenssoort (P/G)

Elk item toont een **badge** die aangeeft of het privévermogen of gemeenschappelijk vermogen betreft:

| Badge | Betekenis |
|-------|-----------|
| **P** (blauw) | Privévermogen — alleen van u |
| **G** (paars) | Gemeenschapsvermogen — van u én uw partner |

> **Waarom is dit belangrijk?** Bij gemeenschap van goederen is de helft van het gemeenschapsvermogen onderdeel van de nalatenschap. Bij privévermogen gaat het volledige bedrag naar de nalatenschap.

---

## 6.4 Bankrekeningen

### Rekening toevoegen

1. Ga naar het tabblad **Rekeningen**
2. Klik op **Toevoegen**
3. Vul de gegevens in:

| Veld | Toelichting |
|------|-------------|
| **Bank** | Naam van de bank (bijv. ING, ABN AMRO, Rabobank) |
| **Rekeningtype** | Betaalrekening, Spaarrekening, Belegging, Deposito of Overig |
| **IBAN** | Het IBAN-nummer van de rekening |
| **Saldo** | Huidige saldo in euro's (€) |
| **Vermogenssoort** | Privé of Gemeenschap |
| **Notities** | Aanvullende informatie |

4. Klik op **Opslaan**

> **Tip:** Het IBAN wordt weergegeven in de lijst zodat nabestaanden rekeningen eenvoudig kunnen identificeren.

---

## 6.5 Verzekeringen

### Verzekering toevoegen

1. Ga naar het tabblad **Verzekeringen**
2. Klik op **Toevoegen**
3. Vul de gegevens in:

| Veld | Toelichting |
|------|-------------|
| **Verzekeraar** | Naam van de verzekeringsmaatschappij |
| **Telefoon** | Telefoonnummer van de verzekeraar |
| **E-mail** | E-mailadres van de verzekeraar |
| **Type** | Soort verzekering (zie hieronder) |
| **Polisnummer** | Het polisnummer |
| **Verzekerd bedrag** | Het verzekerd bedrag in euro's (€) |
| **Begunstigde** | Wie de uitkering ontvangt |
| **Vermogenssoort** | Privé of Gemeenschap |
| **Notities** | Aanvullende informatie |

4. Klik op **Opslaan**

### Verzekeringstypen

| Type | Toelichting |
|------|-------------|
| **Levensverzekering** | Keert uit bij overlijden of op een bepaalde datum |
| **Uitvaartverzekering** | Specifiek voor uitvaartkosten |
| **Overlijdensrisicoverzekering** | Keert uit bij overlijden binnen een bepaalde periode |
| **Woonverzekering** | Opstal- of inboedelverzekering |
| **Autoverzekering** | WA, allrisk, etc. |
| **Zorgverzekering** | Basis- en aanvullende zorgverzekering |
| **Overig** | Andere verzekeringen |

---

## 6.6 Schulden

### Schuld toevoegen

1. Ga naar het tabblad **Schulden**
2. Klik op **Toevoegen**
3. Vul de gegevens in:

| Veld | Toelichting |
|------|-------------|
| **Schuldeiser** | Naam van de schuldeiser |
| **Telefoon** | Telefoonnummer |
| **E-mail** | E-mailadres |
| **Type** | Soort schuld (zie hieronder) |
| **Bedrag** | Openstaand bedrag in euro's (€) |
| **Maandelijkse aflossing** | Maandelijks aflossingsbedrag (€) |
| **Referentie** | Leningnummer of referentie |
| **Vermogenssoort** | Privé of Gemeenschap |
| **Notities** | Aanvullende informatie |

4. Klik op **Opslaan**

### Schuldtypen

| Type | Toelichting |
|------|-------------|
| **Hypotheek** | Woninghypotheek |
| **Persoonlijke lening** | Lening bij een bank of particulier |
| **Studielening** | DUO-lening |
| **Creditcard** | Openstaand creditcardsaldo |
| **Zakelijk** | Zakelijke lening of krediet |
| **Overig** | Andere schulden |

---

## 6.7 Bewerken en verwijderen

Op alle tabbladen:

- Klik op het **potlood-icoon** (✏️) om een item te bewerken
- Klik op het **prullenbak-icoon** (🗑) om een item te verwijderen
