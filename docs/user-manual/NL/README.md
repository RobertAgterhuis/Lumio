## Over Lumio

Lumio is een offline desktop-applicatie waarmee u uw digitale nalatenschap vastlegt — van testament en uitvaartwensen tot digitale accounts en noodcontacten. Alle gegevens worden lokaal en versleuteld opgeslagen. Er is geen internetverbinding nodig.
