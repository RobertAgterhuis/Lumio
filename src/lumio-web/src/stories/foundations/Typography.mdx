# Typography

The typography system uses rem-based sizing for accessibility. All values scale with the user's browser font size settings.

## Font Sizes

All font sizes are defined as CSS custom properties and mapped to Tailwind utilities.

| Token | Size | Pixels (at 16px base) | Tailwind Class |
|-------|------|----------------------|----------------|
| `--text-xs` | 0.75rem | 12px | `text-xs` |
| `--text-sm` | 0.875rem | 14px | `text-sm` |
| `--text-base` | 1rem | 16px | `text-base` |
| `--text-lg` | 1.125rem | 18px | `text-lg` |
| `--text-xl` | 1.25rem | 20px | `text-xl` |
| `--text-2xl` | 1.5rem | 24px | `text-2xl` |
| `--text-3xl` | 1.875rem | 30px | `text-3xl` |
| `--text-4xl` | 2.25rem | 36px | `text-4xl` |

## Grote Tekst Mode (Accessibility)

The `.grote-tekst` class scales all typography tokens larger for users who need bigger text. This is triggered via user preferences in the app settings.

| Original | Grote Tekst |
|----------|-------------|
| 0.75rem (xs) | 0.875rem |
| 0.875rem (sm) | 1rem |
| 1rem (base) | 1.125rem |
| 1.125rem (lg) | 1.25rem |
| ... | ... |

## Usage Guidelines

### Do ✓

- Use `text-sm` for form labels and helper text
- Use `text-base` for body content
- Use `font-semibold` for interactive element labels
- Combine size and weight: `text-2xl font-semibold` for card titles

### Don't ✗

- Don't use arbitrary pixel values like `text-[13px]`
- Don't skip heading levels (h1 → h3)
- Don't use `font-bold` for everything — reserve for true emphasis
- Don't set line-height below 1.25 for multi-line text
