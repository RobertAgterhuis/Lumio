# Colors

The Lumio design system uses a layered color token architecture. All colors are defined in `tokens.css` and mapped to Tailwind utilities via `@theme` in `globals.css`.

## Color Philosophy

- **Primary (Teal)**: Brand identity, primary actions, interactive elements
- **Sage**: Nature/calm feeling, secondary accents
- **Secure (Blue)**: Security indicators, trust signals
- **Semantic Colors**: Success, Warning, Danger, Info for contextual feedback
- **Neutral**: Text, backgrounds, borders

## Usage Guidelines

### Do ✓

- Use semantic colors for their intended purpose (success for confirmations, danger for destructive actions)
- Use primary colors for interactive elements and CTAs
- Reference token names in code: `bg-primary`, `text-danger`

### Don't ✗

- Don't use raw hex values — always use design tokens
- Don't use danger color for non-destructive actions
- Don't mix light/dark mode values manually — the system handles this
