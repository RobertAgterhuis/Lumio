# Spacing

The spacing system follows an 8-point grid with named tokens. Consistent spacing creates visual rhythm and improves scannability.

## Spacing Scale

| Token | Value | Tailwind | Common Use |
|-------|-------|----------|------------|
| `--space-1` | 4px | `p-1`, `m-1`, `gap-1` | Icon padding, tight gaps |
| `--space-2` | 8px | `p-2`, `m-2`, `gap-2` | Form field gaps, button padding |
| `--space-3` | 16px | `p-3`, `m-3`, `gap-3` | Card padding, section gaps |
| `--space-4` | 24px | `p-4`, `m-4`, `gap-4` | Card content, form sections |
| `--space-5` | 32px | `p-5`, `m-5`, `gap-5` | Page margins, major sections |
| `--space-6` | 48px | `p-6`, `m-6`, `gap-6` | Card containers, large spacing |
| `--space-7` | 64px | `p-7`, `m-7`, `gap-7` | Page sections, hero areas |

## Common Patterns

### Card Layout

```tsx
<Card>
  <CardHeader className="p-6">    {/* space-6 for header */}
    <CardTitle>Title</CardTitle>
  </CardHeader>
  <CardContent className="p-6 pt-0">  {/* space-6 sides, 0 top */}
    <div className="space-y-4">   {/* space-4 between items */}
      ...
    </div>
  </CardContent>
</Card>
```

### Form Layout

```tsx
<form className="space-y-6">       {/* space-6 between sections */}
  <div className="space-y-2">      {/* space-2 between label and input */}
    <Label>Email</Label>
    <Input />
  </div>
</form>
```

### Button Groups

```tsx
<div className="flex gap-2">       {/* space-2 between buttons */}
  <Button variant="outline">Cancel</Button>
  <Button>Save</Button>
</div>
```

## Usage Guidelines

### Do ✓

- Use consistent spacing within component types
- Use `space-y-*` and `space-x-*` for uniform gaps
- Use `gap-*` with flexbox and grid layouts
- Start with `space-6` (48px) for page/card containers

### Don't ✗

- Don't use arbitrary spacing like `p-[13px]`
- Don't mix spacing systems (margin + padding for the same gap)
- Don't use `space-1` between major sections — too tight
- Don't add spacing tokens unnecessarily — let components handle their own internal spacing
